Files are read in memory and not stored. Only the extracted text and the review are saved.

How it works

  1. Validate & extract. File type, size and contents are checked, then the text is pulled out.
  2. Analyze. The AI returns strict structured data: each value with a source, a confidence and a supporting excerpt.
  3. Check. Code locates every excerpt in the document. Evidence that isn't there is thrown away, and the value is relabeled or discarded.
  4. Verify. A person approves, edits or rejects each value. Nothing counts as verified before that.
